# Day 12: Job Search & Personal Branding Toolkit

## Task
Built a complete job search and personal branding toolkit tailored to an AI/ML 
Intern role, using a structured 12-section prompt covering cover letters, 
outreach emails, LinkedIn messaging, skill gap analysis, and personal branding — 
followed by a targeted improvement pass to sharpen tone and impact.

## Target Role
AI/ML Intern (Data Science Track)

## Process
1. Sourced/created a realistic AI/ML Intern JD calibrated to a 2nd-year student's 
   skill level
2. Ran the resume + JD through the Job Search & Personal Branding prompt to 
   generate all 12 sections
3. Reviewed ATS recommendations and skill gap analysis
4. Ran a second improvement prompt to strengthen hooks, pull metrics forward, 
   and tighten tone

## Key Outputs
- ATS-optimized cover letter, recruiter outreach email, and hiring manager email
- LinkedIn connection request, referral request, and follow-up email templates
- 30-second professional introduction for interviews/networking
- Top 10 job titles matched to my current profile
- Skill gap analysis: identified missing scikit-learn/applied ML, formal 
  statistics, applied SQL, and cloud deployment experience
- A concrete 4-week learning roadmap (Kaggle micro-course → real SQL queries on 
  my own data → a small regression model → deploying my Flask API)
- Personal brand summary, recruiter headline, and interview talking points

## Key Learnings
- Quantified achievements land harder when pulled to the front of a sentence 
  instead of buried at the end (e.g., leading with "15 simulation modules built" 
  rather than mentioning it mid-paragraph)
- A skill gap analysis is only useful if the roadmap is specific and time-boxed — 
  generic advice like "learn machine learning" isn't actionable, but "complete 
  Kaggle's Intro to ML course in week 1–2" is
- ATS toolkits need to be calibrated to actual experience level; overclaiming 
  skills I don't have would hurt more than help at the applicant screening stage
- Applied AI tooling (Claude, prompt engineering) is itself a differentiator to 
  highlight for a student profile, not just a soft skill
