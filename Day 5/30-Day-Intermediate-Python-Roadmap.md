# 30-Day Coding Roadmap (Intermediate Python, 1 Hour/Day)

**Learner Profile:** Student, already knows Python basics, 1 hr/day, learns best through videos + projects + reading.
**Focus:** Leveling up from "knows Python syntax" to "can build real programs and reason about code" — core data structures, algorithms, and intermediate project-building.

**Format:** ~1 hour/day. Weekdays mix a short video/read (20–30 min) with hands-on coding (30–40 min). Weekends are project-focused.

## Final Outcome

By Day 30 you will:
- ✅ Write cleaner, more idiomatic Python (comprehensions, decorators, lambdas)
- ✅ Understand and implement core data structures (stacks, queues, linked lists, trees)
- ✅ Understand Big O and core algorithms (searching, sorting, two-pointer)
- ✅ Be comfortable solving LeetCode-style problems
- ✅ Have shipped a tested, multi-file real-world project on GitHub
- ✅ Have a clear, informed choice for your next specialization (web dev, data science, or AI/ML)

---

## Tips for Success

- **Type every code example yourself** — even if you understand it by watching, typing builds real recall.
- **Struggle before searching** — give each problem 10–15 minutes of genuine effort before checking a solution.
- **Document as you go** — a short daily note in your GitHub repo turns this into a visible portfolio, not just practice.
- **Don't skip the weekend projects** — they're where the week's concepts actually stick.
