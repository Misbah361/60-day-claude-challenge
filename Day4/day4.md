# Day 4 – Chain-of-Thought Prompting

## 🎯 Task
Used a Chain-of-Thought (CoT) prompt template to generate a personalized 3-month career roadmap 
(Student → AI/Data Internship) with Claude, then reflected on the output.

## 🧠 The Prompt Approach
Instead of asking a vague question like "what career should I pursue," the prompt instructed 
Claude to reason step by step:
1. Ask 4 clarifying questions (situation, skills, goal, timeline)
2. Analyze current position → identify strengths → identify gaps
3. Recommend a learning plan, projects, networking strategy, and milestones
4. Output everything as a structured one-page visual roadmap

## 📋 My Inputs
- **Current situation:** Student
- **Skills:** Python
- **Target goal:** Land an internship
- **Timeline:** 3 months

## 💡 Biggest Insight
The gap isn't "not knowing enough" — it's not having visible proof of skill. The roadmap made it 
clear that shipping 2–3 public projects matters more than consuming more tutorials, and that 
networking should start now, in parallel with learning, instead of after I "feel ready."

## 🔑 Key Learnings
- Chain-of-Thought prompting produces far more structured, personalized output than a single 
  direct question.
- Asking the AI to gather context first (via clarifying questions) before generating output leads 
  to a genuinely tailored result, not a generic template.
- A good roadmap isn't just information — it's decision-ready: clear months, clear actions, clear 
  next step.
